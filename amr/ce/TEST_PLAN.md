# Verification & validation test plan - Giorgio - draft rev B4, 2026-10-05

Each test produces a signed report (date, SW/config CRC, robot S/N, variant, equipment calibration) filed under
Annex IV (g). Numeric limits marked ASSUMED are proposals to be fixed in the SRS. "Lab" = accredited external lab.
Common equipment: calibrated tape/laser distance meter, high-speed camera (>= 240 fps) or encoder logging via
CANopen, floor markings grid, load dummies (2 x 3 kg + 2.1 kg tray), stopwatch/logic analyser on safety I/O.

| ID | Test | Method | Acceptance criteria | Equipment |
|---|---|---|---|---|
| TP-01 | Stopping distance/time vs speed (travel), SS1-t; **thresholds** | trigger protective stop via test piece at 0.3/0.7/1.1 m/s (and max configured), loaded/unloaded, fwd/rev, 10 runs each; log OSSD off -> ramp start -> standstill -> STO (1.2 s); measure the SWD reaction time t_drive (SFRT, VERIFICATION E9) | max measured stop distance + 10 % <= protective field of that band (CALC s.7 rev B2: 251/535/894/1240 mm); ramp ends before the 1.2 s STO at every band; measured t_drive <= 40 ms used in the fields (else recompute); no contact with test piece; **thresholds (rev B3): a sharp 10 mm step crossed at every speed band and a 20 mm step bevelled 1:2 crossed at ≤ 0.3 m/s, forward and reverse, empty and loaded, without wheel spin > 0.5 s or castor flutter; 20 mm sharp step: robot stops (no climb) without damage** | encoder log (CANopen), logic analyser on PNOZ/SR1 contacts, camera, test pieces |
| TP-01b | SS1-t ramp-failure fault injection | disable the SWD quick-stop ramp (fault injection in the non-safe command path), trigger a protective stop at each band | SWD SLS[1] monitoring goes to STO at t_SLS = 1.0 s (PL d) and the PNOZ STO at 1.2 s; measured distance recorded as residual risk H03 (CALC s.7 info table); no runaway | as TP-01 |
| TP-02 | E-stop response | each of 3 E-stops at max speed and with arms moving | stop cat as designed (SF1); measured times <= SRS values; no restart on release, only after reset | logic analyser |
| TP-03a | **Cat-0 stopping distance type test** (ISO 3691-4 brake test; SWD brake torque and phase-short decel are not published, VERIFICATION E3) | (a) power cut (Q0 / K0 open) and (b) STO with the ramp disabled, at 0.3/0.7/1.1 m/s, loaded/unloaded, fwd/rev, dry and worst allowed floor; (c) single drive fault | robot stops straight; distance recorded per band and compared with the ramp-failure / power-loss case of CALC s.7; decel <= tip limit (CALC s.2b SF >= 1.2); no rotation runaway on single drive fault | encoder log, camera, ramp, inclinometer |
| TP-03b | **6 % slope holding test** | loaded robot (166 kg) on a 6 % ramp facing up and down; power off (parking brake) and STO + SBC; 10 min each | no creep > 10 mm in 10 min (requires >= 3.05 Nm per wheel = 0.76 Nm per motor, CALC s.2b); repeat at 1.5 x slope for margin (record) | ramp 6 % (+ 9 %), tape |
| TP-04 | Stability | (a) static tilt: worst config (arms extended sideways, 2x3 kg + tray) on tilting platform; (b) dynamic: max decel/E-stop on max slope downhill, turning at max yaw rate; (c) push test horizontal force at 1.2 m height | (a) no tip at >= rated slope + margin (ISO 3691-4 stability method; criterion ASSUMED >= 2x rated slope); (b) no wheel lift > 10 mm; (c) no tip at 170 N (sim value), recorded tip force | tilt table, force gauge |
| TP-05 | Personnel detection field validation + **static scan-plane height** | ISO 3691-4 test pieces (upright 70 mm leg cylinder, lying 200 mm cylinder - verify dims in standard) at contour corners, sides, rear, during rotation in place; black/low-reflectance clothing; approach from side at walking speed; SICK test object at **every edge of the largest field of each set** (OI 8024596 p.52), robot standing, empty, castors preloaded (TP-23) | detection in all positions of each field set; protective stop before contact; residual gap at body contour <= value in field design; **scan plane 184.5 ± 5 mm at every field edge** (else shim the scanner and repeat) | test pieces, SICK test object, field set report |
| TP-05b | **Scan plane while accelerating / braking** (rev B3, CALC §7b) | drive through each speed band accelerating and braking at the configured limits (rev B4: 0.3: 1.36/0.79, 0.7: 1.15/0.69, 1.1: 0.97/0.61 m/s²); measure the body pitch (inclinometer, 100 Hz) and the plane height at the front / rear field edges (test object detection or laser line on a target) | plane ≤ 200 mm at every field edge (SICK OI p.40); measured pitch ≤ CALC quasi-static pitch × 1.2 (else lower the limits) | inclinometer, test object, data logger |
| TP-06 | Field switching / speed monitoring / reverse limit | drive through every speed band; command speed above the active SLS; command reverse > 0.3 m/s in FAST | field set matches speed band; speed above SLS after the 1.1 s switch delay (t_SLS 1.0 s) -> STO (SF3, SF4); reverse capped at 0.3 m/s or STO by the permanent SLSa in each drive (SF5) ; force each SR2 relay contact open / closed (single faults) -> invalid 1-of-3 code -> both scanners OSSD off; bleed current >= 10 mA per contact | PNOZmulti and scanner logs, SWD CANopen log, DMM |
| TP-07 | SSM separation distance (OpenArm OA / cobot C48) | measure arm stopping time/distance (stop cat used) per ISO 10218-1 method; compute S = Kh*(t1+t2)+Ss+C (EN ISO 13855 / 10218-2 SSM); check arm field covers it (SF7) | protective field >= computed S in all arm work poses | encoders, camera |
| TP-08 | PFL (cobot variant) | measure transient + quasi-static force/pressure at defined body regions (EN ISO 10218-2:2025 biomechanical limits annex, ex ISO/TS 15066) for each hazard point of the application, including gripper | all values below limits for the body region; report per contact point | force/pressure measurement device (e.g. GTE CBSF / Pilz PRMS, calibrated) |
| TP-09 | Arm drop / power loss (OpenArm OA after G1, MR Annex III 1.2.6(d)) | cut power in worst pose with 3 kg payload | arm displacement <= 10 mm (brake) or no fall below safe height (gas spring); payload retained or falls only into tray | tape, camera |
| TP-10 | Travel interlock + payload carriage | try FAST travel with arm unparked or item in gripper; E-stop with full coffee cups in tray | FAST travel refused, slow speed only (SF8); no spill out of tray at E-stop decel | water-filled cups |
| TP-11 | Surface temperatures + coffee stop; **heat-run of the base (rev B4, F3)** | thermocouples on accessible surfaces after 2 h barista cycle; open cover during brew; E-stop and SERVICE during brew. **Heat-run:** climatic room at 35 °C (rated maximum), 2 h logistics duty then 2 h barista duty, covers closed; thermocouples (air, 10 mm from the part) at: SWD electronics cover (inboard end) and gearbox of both drives inside the tunnels E43, tunnel outlet at E44, left/right side bay at the DDR-240 (U4) and PNOZ, centre bay at E50L, DSR clamps; repeat with one bay fan and one tunnel fan stopped (fault case, until the Jetson fan alarm) | **SWD housing air ≤ 40 °C** (SWD rating 0…+40 °C) and tunnel outlet ≤ 40 °C at 35 °C room; side-bay air ≤ 50 °C at U4 (DDR-240 rating) and ≤ 55 °C elsewhere; centre bay ≤ 55 °C; DSR air ≤ 50 °C; fan-fault case: Jetson alarm before any limit is exceeded, then park; surfaces <= EN ISO 13732-1 limits for contact time; cover open -> heater/actuator off (appliance interlock or PNOZ input); E-stop/SERVICE -> K4 off, aux read-back seen by the PNOZ (SF15, PLr b) | thermocouples |
| TP-12 | Modes, reset, warnings, restart | key selector each position (SF14); reset (SF13); power-cycle; network loss; manual hold-to-run with enabling pendant; beacon/buzzer self-check | no unexpected start; manual speed <= 0.3 m/s (ASSUMED); warning devices fault reported | - |
| TP-13 | Dock + charging | pad voltage when not docked / handshake missing (Wi-Fi/Ethernet link down); metal object across pads; undock during charge; docking with test piece near dock; inject > 58.5 V at the pads (lab supply) | pads 0 V (< 1 V) unless Hall + signature + network handshake (SF10); OV relay XD3 (Carlo Gavazzi DUB01CD48500V, 200 V range) bench-calibrated to 58.5 V: trips within 57.5-59.5 V on 10 ramps (RoboPad <= 60 V under fault); K0V (DUB01, 50 V range) opens K0 at 48.0 ± 0.25 V after 5 s; NPB DIP preset reads 56.8 / 53.6 V; no traction while KS is energised (SF11); no arc on undock; docking field stops on test piece (SF9) | DMM, scope, lab supply 0-65 V |
| TP-14 | Battery / electrical | insulation & continuity (EN 60204-1 cl. 18), short circuit at main bus via fuse coordination calc + test on branch fuses, BMS fault simulation (LYNK alarm -> R1 NO drops -> K0 opens; G01 unpowered -> K0 opens), 48 V cut-off (K0V opens K0, Jetson switches packs off), regen into full battery | fuses clear within cable rating; BMS opens contactor; bus <= 58.4 V+margin with shunt | megger, load bank |

| TP-21 | Cybersecurity EN 18031-1 (+ -2) | assess each requirement (access control, authentication, secure update, secure storage, secure comms, logging, resilience); port scan; update signature check; config CRC | all applicable requirements met or justified N/A; safety configs unreachable from network | nmap, docs |
| TP-23 | **Castor preload and suspension** (rev B3) | robot empty on 4 castor scales + 2 drive-wheel scales; set each corner with the C05 bracket slots; push each castor through its travel (−2.5 / +17 mm) by hand jack | each castor 76 ± 7 N; drive wheels ≥ 35 % of the weight each; carriage friction < 5 N (spring scale); pad touches the roof at +17 ± 1 mm; no contact of the swivelling castor with any part over 360° at droop, nominal and bump | scales, feeler gauge, spring scale |

Order: TP-18 early (design risk), then TP-01-06 + TP-12-13 (core 3691-4), TP-07-10 (arms), lab tests TP-17/TP-19 last.
Rev B: the rev A waist test (limits, gap, waist SSM) was deleted and TP-08...TP-23 renumbered TP-07...TP-22.
SF IDs: SF1-SF16 = `../electrical/SAFETY_FUNCTIONS.md` rev B2; SF17 is CE-only. Safety controller: Pilz PNOZmulti 2 (B0 + 2 x EF 4DI4DOR + ES ETH). Rev B2 adds TP-01b, splits TP-03 into TP-03a (cat-0 stopping distance type test) and TP-03b (6 % slope holding), adds TP-19b (dock EMC, NPB-1700 option only).
Rev B4: speed bands 0.3 / 0.7 / 1.1 m/s in TP-01/03a/05b/06 (SLS[2] via SR3 tested in TP-06); fields incl. Z_F (TP-05 at the new field edges, arm-work field with the 50 mm resolution test piece); TP-11 heat-run with the SWD tunnel criteria (F3); TP-14 regen with one DSR disconnected (F5).
Rev B3: TP-05 adds the static scan-plane check at every field edge, TP-05b (plane while accelerating/braking at the per-band limits), TP-01 the threshold rule (sharp ≤ 10 mm at speed, 10-20 mm bevelled 1:2 at ≤ 0.3 m/s), TP-13 the DUB01 relays (XD3 58.5 V, K0V 48.0 V), new TP-23 (castor preload and suspension).
